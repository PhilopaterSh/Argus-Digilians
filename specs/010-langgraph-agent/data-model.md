# Data Model: LangGraph Agent & RAG Pipeline

## Core Entities

### 1. RAG Document Chunk
Represents a parsed piece of knowledge inside the LangChain FAISS index.

**Fields**:
- `id` (UUID): Unique identifier for the chunk.
- `page_content` (String): The actual text content.
- `metadata` (Dictionary): Source file path, page number, or section header.
- `embedding` (Vector/List[Float]): The numerical representation generated by Ollama.

### 2. Tactical Agent State (LangGraph)
The `TypedDict` state object passed sequentially (and cyclically) between LangGraph nodes.

**Fields**:
- `target_ip` (String): The current target being evaluated.
- `open_ports` (List[Int]): Discovered ports from the Recon Node.
- `vulnerabilities` (List[Dictionary]): CVEs or flaws found by the Scanner Node.
- `current_payload` (String): The payload currently staged for the Exploit Node.
- `failed_payloads` (List[String]): Payloads blocked or failed, used by the Reflective Node to craft bypasses.
- `exploit_success` (Boolean): Flag indicating if execution transitioned to Post-Exploit.
- `extracted_data` (Dictionary): Booty/Loot retrieved post-exploitation.

### 3. Blackboard Entry (SQLite)
The persistent record of the agent's findings after execution completes.

**Fields**:
- `id` (Primary Key): Auto-incrementing ID.
- `timestamp` (DateTime): When the data was stored.
- `target` (String): The IP or hostname.
- `state_snapshot` (JSON): A serialized snapshot of the Agent State upon completion.
- `status` (Enum): `SUCCESS`, `FAILED`, `ABORTED`.
