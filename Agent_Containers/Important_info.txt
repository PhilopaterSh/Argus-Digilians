Containers with n8n and WhiteRabbitNeo model:

The one thing you do lose
The current LangChain ReAct loop lets the LLM decide what tool to call next based on previous results. In n8n the workflow is fixed — you define the sequence visually. If you want the LLM to dynamically reason and pick tools, you'd need to add a decision node in n8n that calls Ollama and parses its response to decide the next step — which is doable but more complex to set up than LangChain does it automatically.
