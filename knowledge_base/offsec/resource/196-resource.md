## Overview
Testing Rate Limits Now that you understand several evasion techniques, let’s use them to test an API’s rate limiting. In practice, without rate limiting, API consumers could request as much information as they want, as often as they’d like.

## Key points
As a result, the provider might incur additional costs associated with its computing resources or even fall victim to a DoS attack. In addition, API providers often use rate limiting as a method of monetizing their APIs. Therefore, rate limiting is an important security control for hackers to test. Typically, to identify a rate limit, first consult the API documentation and mar keting materials for any relevant information.
