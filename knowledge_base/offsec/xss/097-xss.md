## Analysis / Response

In short, CVE-2022-4971 is an XSS issue in Sassy Social Share.

The Sassy Social Share plugin for WordPress is vulnerable to Reflected Cross-Site Scripting via the 'urls' parameter called via the 'heateor_sss_sharing_count' AJAX action in versions up to, and including, 3.3.3 due to insufficient input sanitization and output escaping. This makes it possible for unauthenticated attackers to inject arbitrary web scripts in pages that execute if they can successfully trick a user into performing an action such as clicking on a link. It maps to CWE-79.

Root cause: Sassy Social Share fails to escape user-supplied data before placing it in HTML or JavaScript context.

The CVSS v3 base score for CVE-2022-4971 is 6.1, which rates as medium.

Impact: Unauthenticated attackers can inject malicious JavaScript through the urls parameter in the sharing count AJAX action, potentially stealing WordPress user sessions and performing actions on behalf of authenticated users.
