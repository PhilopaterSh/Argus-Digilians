## Scenario

Which vulnerability class best describes CVE-2021-24300 (WordPress WooCommerce <1.13.22 - Cross-Site Scripting)?
A) path traversal
B) broken access control
C) XSS
D) unrestricted file upload

## Analysis / Response

Answer: C) XSS.

Why: The slider import search feature of the PickPlugins Product Slider for WooCommerce WordPress plugin before 1.13.22 did not properly sanitised the keyword GET parameter, leading to reflected Cross-Site Scripting issue CVE-2021-24300 is recorded as CWE-79.

**Remediation:** Implement context-aware output encoding (HTML entity, JavaScript, URL encoding) for all user-controlled data. Deploy Content-Security-Policy headers. Use frameworks with automatic escaping (React, Angular). Validate and sanitize input on the server side.
