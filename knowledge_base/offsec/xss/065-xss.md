## Scenario

How would a SOC detect unrestricted file upload?

## Analysis / Response

Detection approaches for unrestricted file upload:

Review upload handlers for extension/type validation, renaming, storage location and execution permissions. Monitor upload directories for script extensions, double extensions (`.php.jpg`) and new files subsequently requested with query parameters; file-integrity monitoring and web-shell detection rules in EDR help. Optional scanner templates test known vulnerable upload endpoints. PHP `move_uploaded_file($_FILES['f']['tmp_name'], 'uploads/' . $_FILES['f']['name'])`, trust the `Content-Type` header, or check only the extension suffix with a naive regex.

Additional considerations (file upload):
- Re-encoding images strips embedded payloads.
- Serving user files from a separate domain isolates XSS risk.
