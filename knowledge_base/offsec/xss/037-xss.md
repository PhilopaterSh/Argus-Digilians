## Scenario

What damage can prototype pollution cause?

## Analysis / Response

Server-side, pollution can bypass authorization checks (for example an injected `isAdmin` default), cause denial of service, and in some template engines or child-process options lead to remote code execution. Client-side, it can produce DOM XSS through script gadgets. Prototype pollution is a JavaScript vulnerability where attacker-controlled keys such as `__proto__` or `constructor.prototype` are merged into objects, modifying `Object.prototype`.

- Query-string parsers that build nested objects can introduce pollution.
- npm audit flags known vulnerable merge libraries.

**Security Impact:** An attacker can execute arbitrary JavaScript in the victim's browser, potentially stealing session cookies, capturing keystrokes, redirecting users to malicious sites, or performing actions on behalf of the authenticated user.

**Remediation:** Implement context-aware output encoding (HTML entity, JavaScript, URL encoding) for all user-controlled data. Deploy Content-Security-Policy headers. Use frameworks with automatic escaping (React, Angular). Validate and sanitize input on the server side.
