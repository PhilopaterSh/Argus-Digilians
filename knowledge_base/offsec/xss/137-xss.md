Note

 Please note that the intended solution to this lab will only work in Chrome.

## Analysis / Response

This PortSwigger Web Security Academy lab (Expert) covers DOM-based vulnerabilities: "Exploiting DOM clobbering to enable XSS".

## Solution steps

1. Go to one of the blog posts and create a comment containing the following anchors: `<a id=defaultAvatar><a id=defaultAvatar name=avatar href="cid:&quot;onerror=alert(1)//">`
2. Return to the blog post and create a second comment containing any random text. The next time the page loads, the `alert()` is called.

## Vulnerability note

Underlying issue: DOM-based vulnerabilities (CWE-79). Avoid unsafe DOM sinks, validate/encode untrusted data before use in the DOM, and prefer safe APIs.
