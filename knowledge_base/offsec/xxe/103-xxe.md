## Scenario

What ordered steps do you use when hunting XML External Entity (XXE)?

## Analysis / Response

## Overview
Disable external entities and DTD processing in the XML parser; prefer JSON; validate and sanitize uploads.

## Deeper notes
Out-of-band XXE matters when the response does not reflect file contents. Parameter entities and XInclude variants help against partial mitigations. SAML and SOAP remain fertile ground. Upload parsers that accept SVG/XML documents are easy to miss.
