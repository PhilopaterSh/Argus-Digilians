# Habiba Branch Archive

Artifacts extracted from the `argus/Habiba` branch (disconnected orphan
lineage, last commit 2026-05-16) immediately before that branch was deleted.
Everything else on the branch was verified as already present in `main`
(workflow diagrams hash-identical under `docs/` and `docs/history/`, legacy
`Setup/` step scripts superseded by `scripts/ARGUS_INSTALLER.ps1`, and the
quarantined `Argus_Secure_Sync.exe` binary deliberately NOT extracted).

- `DEVELOPMENT_LOG.md` - Habiba's development log (May 2026 milestones).
- `Discovery_cultbeauty_co_uk.txt` - discovery evidence from the live run
  against `cultbeauty.co.uk` that produced the 900-second ReAct parsing
  failure documented in Thesis Section 6.5 / ADR-18.
- `n8n-workflow-notes.md` - n8n integration notes; the only workflow file
  on the branch with no copy anywhere in `main`.
