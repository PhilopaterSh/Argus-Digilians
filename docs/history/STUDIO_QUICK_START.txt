LAUNCHING THE GUI STUDIO:
=========================

⚠️ IMPORTANT: Check Your Hardware First!

For GPU Systems (NVIDIA/CUDA Available):
  $ LAUNCH_STUDIO.bat G  (Fast GPU acceleration)

For CPU-Only Systems (NO GPU):
  $ LAUNCH_STUDIO.bat C  (Stable, slower but reliable)

For Ollama/CUDA Errors:
  $ LAUNCH_STUDIO.bat R  (Clean restart - fixes most issues)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

WHAT EACH MODE DOES:
====================

[G] GPU Mode (Default):
  • Uses NVIDIA CUDA acceleration
  • Fast AI model inference
  • For computers with NVIDIA GPU + drivers
  • If GPU errors appear, try [C] or [R] instead

[C] CPU Mode:
  • Uses system CPU only
  • No GPU required
  • 100% stable
  • Slower than GPU but still usable
  • RECOMMENDED if you don't have GPU

[R] Clean Restart:
  • Stops and restarts Ollama service
  • Clears any stuck processes
  • Fixes most CUDA/GPU errors
  • Good for troubleshooting

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

2. WHAT HAPPENS DURING LAUNCH:
   ✓ Checks if Ollama is running (AI Engine)
   ✓ Starts or verifies WSL SSH Bridge
   ✓ Activates Python Virtual Environment

================================================================================
                          TROUBLESHOOTING
================================================================================

PROBLEM: "SSH Bridge is down"
SOLUTION:
  1. Manually start SSH: wsl -d kali-linux -u root /usr/sbin/sshd
  2. Verify: Test-NetConnection -ComputerName 127.0.0.1 -Port 22
  3. Retry launcher

PROBLEM: "Ollama is NOT running"
SOLUTION:
  1. Ensure Ollama is installed on Windows
  2. Start manually: start "" "ollama app.exe"
  3. Retry launcher after ~10 seconds

PROBLEM: "CUDA Errors" or GPU Issues
SOLUTION:
  1. Run with CPU Mode: LAUNCH_STUDIO.bat C
  2. Or clean restart: LAUNCH_STUDIO.bat R
  3. Check NVIDIA drivers installed

PROBLEM: Streamlit shows import errors
SOLUTION:
  1. Run INSTALL_EVERYTHING.bat first
  2. Ensure Virtual Environment created
  3. Check .env file has correct settings

PROBLEM: Port 8501 already in use
SOLUTION:
  1. Kill existing process: taskkill /F /IM python.exe
  2. Or check: netstat -ano | findstr :8501
  3. Retry launcher
