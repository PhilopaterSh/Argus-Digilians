================================================================================
                    HOW FALLBACK DETECTION WORKS
================================================================================

Browser doesn't show format errors because brain.py catches them:

1. ReAct Agent invoked
2. Error occurs: "Invalid Format..."
3. brain.py detects: "Invalid Format" in error message
4. Switches: self.use_react = False
5. Calls: self._ask_simple_chain(query)
6. Simple Chain: No format constraints, just JSON
7. Result: Analysis completes successfully
8. User: Sees results, not errors


Technical Note:
  • On second query (same session): ReAct skipped entirely
  • use_react flag stays False after first error
  • All subsequent queries use Simple Chain
  • Much faster (no ReAct attempt overhead)

================================================================================
                         SUPPORT & TROUBLESHOOTING
================================================================================

Issue: Browser shows blank page
  Solution: 
    1. Hard refresh: Ctrl+F5
    2. Clear cache: Ctrl+Shift+Delete
    3. Check terminal for errors
    4. Restart: Kill LAUNCH_STUDIO.bat, run again with "C" option

Issue: "SSH Bridge connection failed"
  Solution:
    1. Verify Kali is running: wsl -d kali-linux --exec whoami
    2. Restart SSH: wsl -d kali-linux -u root /usr/sbin/sshd
    3. Check credentials in GUI sidebar

Issue: "Model not found" or Ollama errors
  Solution:
    1. Check Ollama running: ollama list
    2. Pull model: ollama pull WhiteRabbitNeo/WhiteRabbitNeo-V3-7B
    3. Restart Streamlit

Issue: Slow performance
  Solution:
    1. Normal: First run loads model (~30-60 seconds)
    2. Check Ollama logs: C:\Users\[user]\AppData\Local\Ollama\
    3. Reduce system load
    4. Use CPU mode (already enabled)

Issue: Still seeing format errors
  Solution:
    1. Check brain.py updated correctly
    2. Check agent_factory_v2.py exists
    3. Restart Streamlit
    4. Python -c import test to verify modules
    5. Report exact error text
